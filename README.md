# Дукон.tj — все магазины Таджикистана

Статический сайт-справочник магазинов и торговых сетей Таджикистана: супермаркеты, рынки, торговые центры, электроника, онлайн-магазины и одежда.

## Возможности

- 🔍 мгновенный поиск по названию, городу, категории и описанию;
- 🗂️ фильтры по категориям (сайдбар с счётчиками) и по городам;
- 📍 карточки магазинов с окном подробностей (модальное окно);
- ⭐ избранное — сохраняется в localStorage браузера;
- 📱 адаптивная вёрстка, без фреймворков и сборки.

## Запуск

Просто откройте `index.html` в браузере, либо:

```bash
python3 -m http.server 8000
```

и откройте http://localhost:8000

## Как добавить магазин

Все данные лежат в одном файле — `data.js`. Добавьте объект в массив `SHOPS`:

```js
{
  name: "Название магазина",
  cat: "market",            // market | bazaar | mall | tech | online | clothes
  city: "Душанбе",
  site: "https://example.tj",
  desc: "Короткое описание"
}
```

## Структура

- `index.html` — разметка страницы
- `style.css` — стили
- `data.js` — категории и список магазинов
- `script.js` — поиск, фильтры, карточки, избранное
